# Security

Security fixes target the latest published release. This extension processes page text and event details locally and fills Proton's event form only after a user paste. It does not save events.

To report a vulnerability privately, email **Bruce Starlove**: [brucestarlove@gmail.com](mailto:brucestarlove@gmail.com). Include the extension and browser versions, impact, and reproduction steps using synthetic data.

You can also use **Security → Report a vulnerability** on [brucestarlove/extension-protoncal](https://github.com/brucestarlove/extension-protoncal) when GitHub private reporting is available. Do not put credentials, private meeting links, personal calendar data, or an unpatched exploit in a public issue.
